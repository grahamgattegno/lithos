LITHOS — Gemstone Database
==========================

TO RUN:  open index.html in any web browser. No install, no internet needed.

WHAT'S NEW:
Every gemstone now shows a custom faceted ILLUSTRATION (SVG vector art) —
diamond as a round brilliant, ruby as a cushion cut, emerald as a step cut,
opal with play-of-colour, amethyst as a raw crystal cluster, and so on.
Each is colour-accurate and cut-appropriate for that stone.

WHY ILLUSTRATIONS INSTEAD OF PHOTOS:
These are drawn in code, so they are 100% original and yours to sell with
NO licensing or copyright concerns at all. They stay razor-sharp at any size.

WANT REAL PHOTOS INSTEAD?
Drop a .jpg into images/ using the matching name (diamond.jpg, ruby.jpg, etc.)
and it overrides the illustration automatically. Filenames:
  diamond ruby sapphire emerald amethyst topaz opal garnet aquamarine
  tourmaline peridot spinel tanzanite citrine jade alexandrite
  para-ba-tourmaline black-opal benitoite moissanite ammolite painite
  grandidierite larimar musgravite
